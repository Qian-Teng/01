# 老师课堂点名系统

这是一个基于 **Java Swing + MyBatis + H2** 的课堂点名系统示例。程序首次启动会自动创建班级学生数据库，包含学号、姓名、性别和课堂分数。

## 功能

- 使用 MyBatis 管理学生数据库访问。
- 自动生成 30 名班级学生初始数据。
- 图形化界面支持按点名数量、学号关键字、性别筛选学生。
- 点击“确认点名”后输出本次点名学生的姓名、学号、性别和课堂分数。
- 支持给本次点名学生统一加 1 分或减 1 分。
- 支持查看学生课堂分数排名。

## 运行

```bash
mvn exec:java
```

## 构建检查

```bash
mvn test
```
